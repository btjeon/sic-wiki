# TND6396 — SiC: From Challenging Material to Robust Reliability

> **원문**: TND6396/D Rev. 2, March 2024
> **저자**: Catherine De Keukeleire (onsemi Oudenaarde, Belgium)
> **분류**: White Paper — onsemi Quality & Reliability Methodology for SiC
> **위치**: Part III §D (신뢰성) 의 일차 레퍼런스

## 1. Abstract (초록)

Silicon Carbide (SiC) 는 **고포화 전자 드리프트 속도**, **높은 열전도율**, **높은 절연파괴 전계** 등 우수한 물리적 특성을 가진 고전력 전자 디바이스용 차세대 반도체. SiC 기반 시스템은 Si MOSFET 대비 **더 작은 면적에서 더 낮은 손실과 더 빠른 스위칭 속도** 를 달성.

onsemi 는 수십 년간의 Si 기술 노하우 위에, **SiC 재료가 가져오는 고유한 도전 과제** 에 대응하기 위해 적합한 Qualification 방법론을 지속적으로 개발. 본 백서가 다루는 핵심:

- onsemi 의 **설계 → 양산까지의 Quality & Reliability 방법론**
- **Gate Oxide Integrity (GOI)** 중심의 SiC 특화 평가 흐름
- **Cryogenic BTI · Body Diode 열화 · Dynamic Stress** 최신 연구 결과

## 3. 백서 5-Step Methodology

```
Control → Improve → Test & Screen → Characterize → Qualify & Extract Models
```

| Step | GOI 적용 예 |
|---|---|
| **Control** | Control Plan, SPC, Process FMEA |
| **Improve** | Substrate / Epi 결함, 금속 오염, 파티클 저감 |
| **Test & Screen** | Substrate Scan + 다중 inline inspection + Wafer level + Burn-in + Die Sort + Dynamic PAT + 100 % 자동 출하 검사 |
| **Characterize** | Q_BD 비교 (Si 대비 ≈ 50×) — Weibull tail 분석 |
| **Qualify & Extract Models** | 전도 메커니즘 식별 (TAT / FN), Arrhenius + E-model, 21 V · 20년 · 5 ppm |

## 4. 핵심 결론

| 영역 | 결론 |
|---|---|
| **Gate Oxide Q_BD** | onsemi Planar SiC 의 Intrinsic $Q_{BD}$ ≈ Si × 50 (5 mA/cm², Forward Bias Gate, RT) |
| **TDDB 수명** | 175 °C / < 9 MV/cm 조건에서 **$V_{gs}$ = 21 V 에서 5 ppm 기준 20년 수명** |
| **BTI** | UF-BTI + CET Map + Comphy 로 **응용 fast 성분 + 장기 slow 성분** 분리, Cryogenic 까지 측정 범위 확장 |
| **Body Diode** | BPD 개별 매핑 + 고도핑 Epi Buffer + SOA 명시 = **1200 V 급 영향 실용적으로 0** |
| **Dynamic Gate Stress** | onsemi 1200 V 80 mΩ 가 타사 3사 대비 −8 V ↔ +20 V 50 % duty 조건에서 우위 |
