# 용어집 (Glossary)

알파벳 / 한글 순으로 정렬.

## A

- **ADAS** — Advanced Driver Assistance Systems
- **ASM (Allotrope Simple Model)** — 실험실 데이터 표준 포맷
- **ASML** — 네덜란드 노광기 제조사 (Twinscan series)

## B

- **BCD** — Bipolar-CMOS-DMOS 공정 — Power IC 통합 공정
- **BEOL** — Back-End-Of-Line — Metal/ILD/Pad 등 후공정
- **BPD** — Basal Plane Dislocation — SiC 신뢰성 핵심 결함
- **BV (BVDSS)** — Breakdown Voltage

## C

- **CD** — Critical Dimension — 패턴 최소 폭
- **CDU** — Critical Dimension Uniformity
- **CMM** — Compact Modeling Method (resist model)
- **CPE** — Correctable Per Exposure (overlay)

## D

- **DOF** — Depth of Focus
- **DMOS** — Double-diffused MOSFET — Planar SiC MOSFET 별칭

## E

- **EPE** — Edge Placement Error — OPC 평가 지표
- **Epi** — Epitaxy — 결정 위에 결정 성장

## F

- **FDC** — Fault Detection & Classification
- **FEM** — Focus-Exposure Matrix
- **FEOL** — Front-End-Of-Line — 트랜지스터 형성 공정

## G

- **GAT** — Graph Attention Network
- **GNN** — Graph Neural Network

## H

- **H3TRB** — High Humidity High Temperature Reverse Bias
- **HTGB** — High Temperature Gate Bias
- **HTRB** — High Temperature Reverse Bias

## I

- **ILD** — Inter-Layer Dielectric
- **ILT** — Inverse Lithography Technology

## J

- **JEDEC** — 전자부품 표준 단체

## K

- **KOH etch** — Potassium Hydroxide etching — SiC 결함 검출

## L

- **LDI** — Linear Drift Indicator / 또는 사내 공정명
- **LIMS** — Laboratory Information Management System

## M

- **MV** — Machine Vision

## N

- **NA** — Numerical Aperture
- **NO anneal** — Nitric Oxide anneal — SiC gate oxide Dit 저감

## O

- **OPC** — Optical Proximity Correction
- **Overlay** — Layer 간 정렬 정확도

## P

- **PL** — Photoluminescence — SiC 결함 비파괴 검출
- **PR** — Photoresist

## R

- **RCA** — Root Cause Analysis
- **Ron** — On-resistance

## S

- **SECS/GEM** — SEMI 통신 표준 (장비 ↔ MES)
- **SF** — Stacking Fault
- **SIC / SiC** — Silicon Carbide
- **SPC** — Statistical Process Control
- **SRAF** — Sub-Resolution Assist Feature

## T

- **TDDB** — Time Dependent Dielectric Breakdown
- **TED** — Threading Edge Dislocation
- **TSD** — Threading Screw Dislocation

## V

- **ViT** — Vision Transformer

## W

- **Weco rule** — Western Electric Rule (SPC)

## 한글

- **공정 능력 지수 (Cp/Cpk)** — process capability index
- **신뢰성 시험** — Reliability test
- **활성화 어닐링** — Activation anneal (Implant 후 1700℃)
