# Glossary

Sorted alphabetically.

## A

- **ADAS** — Advanced Driver Assistance Systems
- **ASM (Allotrope Simple Model)** — Standard format for laboratory data
- **ASML** — Dutch lithography-tool manufacturer (Twinscan series)

## B

- **BCD** — Bipolar-CMOS-DMOS process — integrated process for Power ICs
- **BEOL** — Back-End-Of-Line — Metal / ILD / Pad and other post-FEOL steps
- **BPD** — Basal Plane Dislocation — key SiC reliability defect
- **BV (BVDSS)** — Breakdown Voltage

## C

- **CD** — Critical Dimension — minimum pattern width
- **CDU** — Critical Dimension Uniformity
- **CMM** — Compact Modeling Method (resist model)
- **CPE** — Correctable Per Exposure (overlay)

## D

- **DOF** — Depth of Focus
- **DMOS** — Double-diffused MOSFET — alias for Planar SiC MOSFET

## E

- **EPE** — Edge Placement Error — OPC evaluation metric
- **Epi** — Epitaxy — crystal growth on a crystal substrate

## F

- **FDC** — Fault Detection & Classification
- **FEM** — Focus-Exposure Matrix
- **FEOL** — Front-End-Of-Line — transistor-formation process

## G

- **GAT** — Graph Attention Network
- **GNN** — Graph Neural Network

## H

- **H3TRB** — High Humidity High Temperature Reverse Bias
- **HTGB** — High Temperature Gate Bias
- **HTRB** — High Temperature Reverse Bias

## I

- **ILD** — Inter-Layer Dielectric
- **ILT** — Inverse Lithography Technology

## J

- **JEDEC** — Electronic-components standards body

## K

- **KOH etch** — Potassium Hydroxide etching — used for SiC defect detection

## L

- **LDI** — Linear Drift Indicator (or in-house process name)
- **LIMS** — Laboratory Information Management System

## M

- **MV** — Machine Vision

## N

- **NA** — Numerical Aperture
- **NO anneal** — Nitric Oxide anneal — reduces $D_{it}$ in SiC gate oxide

## O

- **OPC** — Optical Proximity Correction
- **Overlay** — alignment accuracy between layers

## P

- **PL** — Photoluminescence — non-destructive detection of SiC defects
- **PR** — Photoresist

## R

- **RCA** — Root Cause Analysis
- **Ron** — On-resistance

## S

- **SECS/GEM** — SEMI communication standard (equipment ↔ MES)
- **SF** — Stacking Fault
- **SIC / SiC** — Silicon Carbide
- **SPC** — Statistical Process Control
- **SRAF** — Sub-Resolution Assist Feature

## T

- **TDDB** — Time Dependent Dielectric Breakdown
- **TED** — Threading Edge Dislocation
- **TSD** — Threading Screw Dislocation

## V

- **ViT** — Vision Transformer

## W

- **WECO rule** — Western Electric Rule (SPC)

## Process / Reliability Terms

- **Process Capability Index (Cp / Cpk)** — measures how well a process fits within spec limits
- **Reliability test** — stress testing for long-term failure prediction
- **Activation Anneal** — post-implant 1700 ℃ anneal to electrically activate dopants in SiC
